## 🧭 知识图谱结构

```
00-MOC/          ← 入口地图（只读，人工维护）
02-项目管理/     ← 跨模块管理文件
10-项目/         ← 项目交付物
  基线/          ← 当前稳定事实源（模块 README / PRD / 资料摘要）
  迭代/260725迭代/ ← 当前迭代工作台（扁平工作稿 / 台账 / 归集清单）
20-资料/         ← 原始资料（只引用不编辑）
20-资料/参考系统/ ← 外部系统 / 竞品系统 / 已上线系统采集资料
30-规范/         ← 输出规范
40-决策/         ← 按季度决策日志
50-经验/         ← 教训库
60-归档/         ← 历史版本存档
90-模板/         ← 新建文件模板
知识库工程化/    ← 个人库、团队库、领域库联动治理
```

> ⚠️ 智能体白名单：常规写入优先进入 `10-项目/迭代/260725迭代/`、`02-项目管理/`、`40-决策/`、`50-经验/`、`60-归档/`、`知识库工程化/`。
> `10-项目/基线/` 仅允许在封版归集或用户明确授权时写入。
> `00-MOC/`、`20-资料/`、`30-规范/` 只读。
