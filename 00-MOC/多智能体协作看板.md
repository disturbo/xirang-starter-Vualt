## Agent 实时状态

> 数据源 = `02-项目管理/智能体状态/` 下 per-agent 文件，Dataview 自动渲染。

```dataview
TABLE
  agent_cn AS "Agent",
  status AS "状态",
  current_task AS "当前任务",
  last_heartbeat AS "最近心跳"
FROM "02-项目管理/智能体状态"
SORT agent_id ASC
```

### 异常检测

```dataview
TABLE
  agent_cn AS "Agent",
  current_task AS "故障任务",
  last_heartbeat AS "最后心跳"
FROM "02-项目管理/智能体状态"
WHERE status = "error"
SORT last_heartbeat DESC
```
