# 30-规范 · 规范索引

> **定位**：本目录存放所有现行规范文件，是 AI agent 和协作者了解"怎么写"的唯一入口。
> **权限**：`30-规范/` 为**只读区**，修改须登记并同步变更日志。
> **治理**：每个约束主题只允许一个权威文件定义。新建/修改规范前**必须先查本索引**确认是否已有文件管辖该主题。

---

> **部署提醒**：本 starter 仅包含通用规范。请根据你的项目需求生成专属规范（如项目硬约束、UI 规范、数据字典等），放置到本目录下。可参考 [[PRD输出规范-通用版-v1.0]] 的格式编写。
