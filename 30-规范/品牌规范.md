## 0 使用方式

**Agent 在以下场景必须查本规范**：写 PRD 文案时、生成原型 UI 时、产出设计方案时、命名单据/状态时。

**查表路径**（不需要通读全文）：

```text
你在做什么？
 ├─ 写品牌名称/产品名？→ §1 查允许列表
 ├─ 选颜色/定义 CSS 变量？→ §2 取 token
 ├─ 写单据编码？→ §3 查编码规则 + 编码映射表
 ├─ 设计列表页操作按钮？→ §4 查按钮约束
 ├─ 写 Toast/提示文案？→ §5 查文案模板
 └─ 不确定是否违规？→ §6 自检 grep 命令
```

## 2 品牌色

### 2.1 色值查表

| 场景 | CSS 变量 | 色值 | 用法 |
|------|---------|------|------|
| 主色背景/品牌标识 | `--color-brand` | `#861B2F` | 顶栏背景; 主按钮填充; 品牌标题 |
| 鼠标悬停/浅色背景 | `--color-brand-light` | `#A8435A` | hover 态; 浅色卡片背景; tag 底色 |
| 按压/深色强调 | `--color-brand-dark` | `#6A1525` | active 态; 深色区域文字; 边框强调 |

### 2.2 生成模板（CSS）

```css
/* 直接复制到原型 HTML 中 */
:root {
  --color-brand: #861B2F;
  --color-brand-light: #A8435A;
  --color-brand-dark: #6A1525;
}
```

### 2.3 禁止色值

不得使用其他红色系色值代替品牌色。以下为常见错误：

| 禁止 | 原因 |
|------|------|
| `#FF0000` / `red` | 纯红不是品牌色 |
| `#C0392B` | 偏橙红 |
| `#E74C3C` | 过亮 |

## 3 单据编码

### 3.1 编码结构

```text
┌─────────┬────────┬────────┬───────┐
│ 主体编码  │  日期   │ 业务码  │ 流水号 │
│  7 位    │ YYMMDD │  2 位   │  3 位  │
└─────────┴────────┴────────┴───────┘
总长度：18 位定长
```

> 主体编码 = 门店编码或总部编码，统一 7 位；日常展示带 `-` 时，写入单据号需去掉分隔符。

### 3.2 生成模板

```text
{主体编码}{YYMMDD}{业务编码}{流水号}
示例：YJHBZ01 260425 PD 001
解读：YJHBZ01主体 + 2026年4月25日 + 取送车(PD) + 第001单
```

### 3.3 业务编码映射表

| 编码 | 业务类型 | 编码 | 业务类型 |
|------|---------|------|---------|
| MB | 维保预约 | GW | 商务补偿 |
| PD | 取送车 | GS | 商务补偿结算 |
| PK | 预检 | JF | 旧件返厂申请 |
| RP | 维修工单 | JY | 旧件返运单 |
| CR | 客述单 | JR | 旧件入库通知 |
| SP | 服务套餐 | JC | 旧件差异处理 |
| SA | 服务活动 | JD | 旧件销毁 |
| RE | 道路救援 | - | - |

> 新增单据类型必须先申请 2 位编码并在本表登记。

## 4 列表操作按钮

### 4.1 规则

- 每行最多 4 个操作按钮
- 前 3 个为高频操作（按业务优先级排列）
- 第 4 位固定为「更多」下拉菜单

### 4.2 生成模板

```markdown
<!-- PRD 中列表操作按钮的标准写法 -->
| 操作按钮（左→右） | 说明 |
|------------------|------|
| 查看 | 跳转详情页 |
| 编辑 | 仅草稿态可用 |
| 提交 | 触发审批流 |
| 更多 ▼ | 下拉：作废 / 导出 / 打印 |
```

## 5 Toast/提示文案

### 5.1 规则

直接写中文双引号包住的终稿文案，禁止"提示用户XXX"模糊描述。

### 5.2 查表：常见场景文案模板

| 场景 | 正确写法 | 错误写法 |
|------|---------|---------|
| 保存成功 | "保存成功" | 提示用户保存成功 |
| 提交成功 | "提交成功，等待审批" | 系统给出提交成功提示 |
| 删除确认 | "确认删除该记录？删除后不可恢复" | 弹窗确认是否删除 |
| 必填校验 | "{字段名}不能为空" | 校验必填字段 |
| 权限不足 | "当前角色无此操作权限" | 提示无权限 |
| 状态冲突 | "当前单据已{状态}，无法{操作}" | 提示状态不允许 |

## 6 自检命令（校验兜底）

写完文档后跑一遍：

```bash
# 品牌词违规检测
grep -nE "协作助手奕派|协作助手纳米|协作助手风神|启境|奕派|eπ|营销赋能系统" <文件>

# 技术类型泄漏检测（PRD专用）
grep -nE "String|Int|Long|Date|Boolean|BigDecimal|varchar" <文件>

# 代码术语泄漏检测
grep -nE "chip|form|APPROVING|JSON|null|undefined|callback" <文件>
```

> 以上 grep 结果应全部为空。非空即违规。
