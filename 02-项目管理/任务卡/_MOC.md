# 任务卡 MOC

> 不靠目录扫描找任务。本文件汇总当前态势。

## 目录结构（v1.1 - 纯月份分桶）

```
02-项目管理/任务卡/
├── _MOC.md              <- 你在这里（任务索引）
├── _template.md         <- 新建卡模板
├── 2026-05/             <- 2026年5月所有任务卡
│   └── T-YYYYMMDD-NN.md
└── 2026-06/             <- 下月（月份翻页时自动创建）
```

**唯一分类维度 = 月份。状态由 frontmatter `status` 字段管理。**
不存在 `进行中/` `已完成/` `已放弃/` `归档/` 等按状态分的文件夹。

**铁律：**
1. **开卡条件**：仅 M4/M5 任务才开 task card（V8 S3 触发路由器）
2. 新卡只进当月 `YYYY-MM/` 目录
3. 状态写在 frontmatter `status` 字段：`ready / in_progress / done / blocked / cancelled`
4. 查当前任务只读当月目录 + 本 MOC，历史月份默认不扫
5. 月份翻页本身即归档 -- 无需显式 move 操作
6. task card 不承载全部产物 -- PRD/报告/retrospective 放业务目录，card 只放链接
7. 任务卡从创建到完成始终留在同月目录，不因状态变更而移动文件

**变更记录：**
- v1.1（2026-05-21）：消除按状态分文件夹（进行中/已完成/已放弃/归档），历史卡统一迁入 `2026-05/`，单一按月分桶
- v1.0（2026-05-19）：初版，按月分桶 + 历史文件夹共存
