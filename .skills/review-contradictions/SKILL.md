# Review Contradictions

## When

出现以下情况时使用：

- 不同资料对同一功能描述不一致。
- 菜单编号、模块边界、路径映射冲突。
- PRD 与原型、规范、飞书文档不一致。
- agent 产物互相覆盖或结论相反。

## Steps

1. 不要立即改 PRD 掩盖冲突。
2. 记录冲突对象、证据路径、影响范围。
3. 将冲突分级：P0 阻塞交付 / P1 影响理解 / P2 可后补。
4. 给出建议判断，但标明“推断”或“待确认”。
5. 写入看板 blocked by，必要时同步决策日志。

## Contradiction Block

```markdown
### C-{YYYYMMDD}-{序号} · {冲突标题}

| 项 | 内容 |
|---|---|
| 冲突点 |  |
| 证据 A |  |
| 证据 B |  |
| 影响范围 |  |
| 建议处理 |  |
| blocked by |  |
```

## Quality Bar

- 冲突必须有证据路径。
- 建议不能伪装成事实。
- P0/P1 冲突解决前，不发布受影响文档。
