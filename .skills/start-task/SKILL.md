# Start Task

## When

任一 agent 开始 vault、PRD、原型、资料整理、评审或规范相关任务时使用。

## Check

- 当前焦点：读 `00-MOC/{项目名}-MOC.md`。
- 协作状态：读 `00-MOC/多智能体协作看板.md`。
- 模块入口：优先读 `10-项目/{项目名}/{模块}/README.md`；没有 README 时读模块同名笔记。
- 约束：读相关 `30-规范/` 文件。

## Steps

1. 判断任务属于 source、summary、published、prototype、standard 哪一层。
2. 确认 owner、next action、blocked by、产物路径。
3. 检查看板是否已有其它 agent 占用同一文件。
4. 只在必要范围内读取文件。
5. 开始修改前，说明将编辑哪些文件。

## Quality Bar

- 能说清楚本次任务的输入、输出、目标路径。
- 不把“读到了”误写成“已验证”。
- 不覆盖其它 agent 未提交的内容。
