# Ingest Source

## When

处理新业务文件、飞书文档、会议纪要、截图、竞品采集、系统导出表格时使用。

## Check

- Source 是否已有存放路径。
- 目标模块是否已存在资料摘要。
- 是否涉及敏感信息或不可外传内容。
- 是否有多份来源互相矛盾。

## Steps

1. 原始文件只登记路径和来源，不整段搬进 PRD。
2. 抽取为模块资料摘要：背景、角色、流程、字段、状态、权限、接口、待确认。
3. 每条摘要尽量保留来源指针：文件名、页签、章节、截图编号、飞书段落。
4. 冲突进入 `review-contradictions`，不要直接择一。
5. 摘要完成后在看板写 handoff。

## Output

优先写入：

```text
10-项目/示例项目EXAMPLE/{模块}/资料摘要.md
```

如果还无法确定模块，先写入：

```text
20-资料/业务文件/{资料名}-摘要.md
```

## Quality Bar

- 摘要不是原文堆叠。
- PRD 可直接引用摘要层。
- 关键判断能追溯到 source。
