# Handoff Task

Use the existing task identity and authoritative state when XiRang is active. A handoff transfers context only; it never expands scope, renews a lease, or accepts a delivery.

Record:

- objective and task identity;
- completed work and exact artifact paths;
- current stage and latest verification;
- next concrete action;
- blockers and the party able to resolve them;
- relevant decisions, assumptions, and failed approaches;
- remaining risks and acceptance owner.

Refresh the handoff before context compression, a substantive stage change, or the end of a working session. Do not claim another Agent is authorized merely because it can read the handoff.
