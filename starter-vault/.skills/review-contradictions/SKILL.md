# Review Contradictions

1. State the exact proposition in conflict; avoid broad claims that whole documents disagree.
2. Cite both sides with file paths, headings, dates, versions, or other stable source pointers.
3. Classify impact: blocking delivery, affecting interpretation, or safe to defer.
4. Separate confirmed facts, inference, and proposed resolution.
5. Check scope and authority: a project rule may validly override a generic rule, and a newer source may supersede an older one only when lifecycle evidence supports that conclusion.
6. Do not hide the conflict by editing one artifact first. Record the conflict, obtain the needed decision, then update every affected consumer.
7. Close the item only after the chosen truth source and downstream updates are verifiable.
