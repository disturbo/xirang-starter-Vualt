# 息壤规范管辖权

每个规则域只允许一个 primary。说明文档、历史设计、测试报告和平台配置不得反向改写 primary。

机器可读真源是 `.xirang/contract/governance-jurisdiction.json`；本页只解释人类应如何理解和裁决，不复制机器 JSON。

## 冲突处理

1. 机器契约、根规则、维护协议和 StateStore 优先于方法论说明。
2. supporting 与 primary 冲突时按 primary 执行，并修 supporting。
3. `historical/retired` 文件及 Git 历史只作背景。
4. 一次性审查报告、执行矩阵和发布清单不能晋升为规则真源。
