## 真源顺序

1. `.xirang/contract/policy.yaml`：平台无关机器契约。
2. `.standards/agent-contract.yaml`：Agent 结构化契约。
3. 根 `AGENTS.md`：工作区行为入口。
4. `.xirang/adapters/PROTOCOL.md`：维护流程与证据要求。
5. 外置 SQLite StateStore：当前授权、任务、阶段、收据和验收状态。
6. 本目录文档：解释与索引，不反向改写前五项。

机器工具登记在 `.xirang/contract/tool-registry.json`，机器管辖权登记在 `.xirang/contract/governance-jurisdiction.json`。它们是基建契约，不在本目录复制第二份日期版 Markdown。

精确版本、披露字段、阶段、退役能力和工具状态由 `python3 .standards/xirang-task.py contract-lint` 校验。lint 只检查受控事实，不禁止正文用人话完整解释同一个机制。

## 收录边界

- 收录：方法论正文、边界定义、稳定运行协议、规范管辖权和当前架构图。
- 不收录：阶段方案、需求卡、实施设计、版本时间线、测试报告、一次性拍板清单、工具验证快照和事故复盘。
- 教训统一进入 [[../教训库|教训库]]；技术探索、能力演变和借鉴评估进入 `50-经验/Agent进化/`；角色与工作模板进入 `70-模板/`。
- 历史方案和被正文吸收的旧文档从实时 Vault 删除，需要追溯时使用 Git 历史。
- 当前版本以机器契约、根规则和正文 frontmatter 为准，不再维护独立版本演变索引。
- V8/V8.5 兼容脚本和历史回归测试属于基建迁移资产，保留在实现目录并登记为 `migration_legacy`，不搬回本目录，也不进入现行信任集。
