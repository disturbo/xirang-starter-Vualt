# 息壤 V9.7 Agent 根约束规范

Agent 根入口只负责让宿主发现息壤协议，不能复制第二套业务规则、角色人格或运行状态。平台模板必须保持下列共同语义：

1. 当前用户自然语言是最高授权来源；Agent 不能代替用户生成授权或验收。
2. 写入和副作用前一次性展示目标、精确范围、排除项、影响、恢复路径与验收方。
3. 授权绑定不可变执行包络，不绑定 Agent；原范围内连续实施、验证、修复和提交。
4. StateStore 是任务、租约、阶段、证据与验收的唯一权威；Markdown 只是投影。
5. 接手 Agent 继续同一任务，handoff 只传上下文，不授予权限。
6. 每次成功写入形成目标路径与最终 SHA-256 绑定证据；失败停止正式交付。
7. 执行者只提交待验收，禁止自验收。
8. M3/M4/M5、固定六 Agent、亮灯、旧心跳、二元触发器与旧 Gate 信任链已退役。

平台入口升级只替换 `XIRANG-V97-PLATFORM` 标记区块，保留区块外宿主或用户规则。文件存在不等于宿主已加载；只有当前行为 canary 才能提升状态。平台登记是开放注册表，不是固定 Agent 名单；未知平台使用通用工作区入口，不猜测或写入未知用户目录。
