# 工作台

这里是日常使用入口。你不需要理解安装器、StateStore 或插件目录，只要从自己的目标出发。

## 我现在要做什么

| 目标 | 从这里开始 |
|---|---|
| 第一次使用 | 先读 [[🏠-Home]]，再把根目录 `AGENT-SETUP.md` 交给当前 Agent |
| 新建项目 | 从 [[70-模板/T-项目首页]] 复制一份到 `10-项目/项目名/` |
| 整理外部资料 | 把原始文件放入 `20-资料/`，使用 [[70-模板/T-资料摘要]] 记录来源与结论 |
| 写 PRD | 使用 [[70-模板/T-PRD]]，并遵守 [[30-规范/通用PRD输出规范]] |
| 记录会议 | 使用 [[70-模板/T-会议纪要]] |
| 记录重要选择 | 使用 [[70-模板/T-决策记录]] |
| 沉淀经验教训 | 使用 [[70-模板/T-经验教训]]，稳定结论再进入 [[50-经验/教训库]] |
| 画业务流程 | 先读 [[30-规范/流程图绘制规范]] |
| 画架构关系 | 先读 [[30-规范/SVG架构图设计规范]] |
| 查看随包能力 | 打开 [[Skill-Inventory]]；目录存在不等于外部能力已经接通 |

## 直接让 Agent 帮忙

把下面一句话中的目标替换成自己的事情：

> 请在当前工作区帮助我完成：{目标}。先读取根 `AGENTS.md` 和息壤协议，只读确认现状；需要修改时，用简单的话一次说明会改哪里、不改什么、如何恢复和由谁验收，等我确认后连续完成并验证。

如果要检查当前环境，可以说：

> 请只读检查这个息壤包是否完整、当前息壤是否已经激活，以及 Skill 清单里哪些能力现在真的可用。不要把“文件存在”当成“已经接通”，缺少 CLI、网络或授权时直接说明。

## 当前状态怎么看

本页不保存静态绿灯，也不猜测任务状态。需要状态时，让当前 Agent 从以下真源现场检查：

1. 完整包 Manifest 与校验结果；
2. `.xirang/local-config.json` 绑定的运行根；
3. SQLite StateStore 中的任务、交付和验收状态；
4. 当前平台入口与 canary；
5. 外部 CLI、账号和网络的当前可用性。

没有新鲜证据时，真实状态只能是“未验证”或“未启用”。
