# 欢迎使用息壤

这是一个已经整理好的空白知识库。它保留通用结构、方法论、规范和模板，不包含任何人的账号、密钥、项目资料或历史任务。

## 第一次使用

1. 在 `10-项目/` 新建你的第一个项目文件夹。
2. 把原始资料放入 `20-资料/`，不要直接改写原始文件。
3. 从 `70-模板/` 复制合适模板，开始写项目笔记、决策或经验。
4. 需要 Agent 帮忙时，直接说你想完成什么；Agent 会先说明修改范围，再开始工作。

## 和 Agent 开始协作

可以直接复制下面这句话：

> 请在当前息壤工作区帮助我完成这件事：{写下你的目标}。先读取根 AGENTS.md 和息壤协议，只读了解现状；涉及修改时，先用简单的话告诉我会改哪里、不会动什么、失败后怎么恢复，等我确认后再连续完成并验证。
