# 欢迎使用息壤

这是一个已经整理好的空白知识库。它保留通用结构、方法论、规范和模板，不包含任何人的账号、密钥、项目资料或历史任务。

## 第一次使用

1. 解压完整包，在 Obsidian 中选择“打开本地仓库”，选中整个解压目录。
2. 如果 Obsidian 提示是否启用随包社区插件，确认列表来自本包后再启用；不需要登录任何账号。
3. 把根目录 `AGENT-SETUP.md` 交给当前任意可访问本机文件的 Agent，让它先校验并完成息壤激活。
4. 在 `10-项目/` 新建第一个项目文件夹，把原始资料放入 `20-资料/`。
5. 从 `70-模板/` 复制合适模板；需要 Agent 帮忙时，直接说你想完成什么。

这个完整包已经带有 Things 主题、通用 CSS、必要 Obsidian 插件和可移植 Skill。插件不带个人配置；需要账号、网络或外部工具的 Skill 仍会先检查当前环境。

日常使用从 [[00-MOC/工作台]] 开始。

## 和 Agent 开始协作

可以直接复制下面这句话：

> 请在当前息壤工作区帮助我完成这件事：{写下你的目标}。先读取根 AGENTS.md 和息壤协议，只读了解现状；涉及修改时，先用简单的话告诉我会改哪里、不会动什么、失败后怎么恢复，等我确认后再连续完成并验证。
