# 息壤 V9.7 工作区入口

本段由息壤安装器维护。项目自己的规则应写在本段之外；升级时会原样保留。

- 在任何写入、删除、外发、发布或有副作用的命令前，先读取 `.xirang/adapters/PROTOCOL.md` 与 `.xirang/contract/policy.yaml`。
- 用户目标匹配随包 Skill 时，先读取 `.skills/RESOLVER.md`，再完整读取最小充分的 `SKILL.md`；Skill 不扩大当前授权。
- Skill、插件或配置存在只表示可发现。依赖 CLI、网络、账号、Token、Cookie、浏览器或应用连接的能力，必须用当前调用证据确认，未验证时报告真实降级状态。
- 只读任务直接完成。写入前一次性向用户说明目标、精确范围、排除项、外部影响、恢复路径与验收方。
- 用户授权绑定已经展示的执行包络，不绑定 Agent；原范围内连续实现、验证、修复并提交，不重复确认。
- 当前状态唯一真源是外置 SQLite StateStore；任务卡和状态页只是单向投影。
- 任务卡、五步工作流和开工仪式仍然存在，但属于面向人的压缩视图；机器阶段以 Policy 为准。
- 多 Agent 接手同一主任务，不新建替代业务任务；handoff 只传上下文，不扩大权限。
- 每次成功写入后立即形成与目标路径及最终 SHA-256 绑定的证据；证据失败时停止正式交付。
- 执行者只能提交待验收，禁止验收自己的交付。
- M3/M4/M5、固定六 Agent、亮灯、旧心跳、二元触发器和 pre-flight 已退役，不得作为现行权限或状态依据。
