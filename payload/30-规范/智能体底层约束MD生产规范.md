# 智能体底层约束 MD 生产规范

底层约束文件负责把 Agent 引到工作区规则和机器契约，不负责写死人格、固定角色或当前运行状态。

## 最小内容

- 进入工作区后应读取的根规则与共享协议。
- 写入、删除、外发和发布前的边界说明义务。
- 项目规则、用户内容和息壤受管区的优先关系。
- 证据、恢复、审核与他人验收要求。
- 未验证能力不得报告为已接通。

## 禁止内容

- 真实姓名、账号、个人目录和项目业务规则。
- API 密钥、访问令牌、Cookie 或恢复码。
- 固定 Agent 名单、永久路径 Owner 或基于角色名的权限。
- 把配置存在、模板存在或旧测试结果写成当前能力证明。

平台模板只提供入口差异；共同规则应引用同一个工作区真源，避免多份复制漂移。
