# Agent 开工边界展示规范

只读查看可以直接完成。写入、删除、移动、外发、发布或运行有副作用的脚本前，Agent 应一次性用普通人能看懂的话展示本次边界。

## 最小展示

- 目标：这次最终要完成什么。
- 写入范围：会改变哪些明确位置。
- 排除项：明确不会碰什么。
- 不可逆与外部影响：是否删除、覆盖、发送、发布或切换生产。
- 恢复方式：失败时依靠什么回到原状。
- 验收方：谁决定结果是否被接受。

## 执行规则

1. 用户对当前边界作出明确执行决定后，同一范围内连续实现、验证和修复。
2. 只有目标或权限扩大、出现新的不可逆动作、需要外发发布，或发生重大方向选择时，才重新请求决定。
3. 平台、Agent 名称和角色不能替代授权；handoff 也不能传递权限。
4. 执行者可以报告 `submitted`，不能把自己的交付写成 `accepted`。

机器字段由 `.xirang/contract/policy.yaml` 规定；Agent 行为入口由根 `AGENTS.md` 与 `.xirang/adapters/PROTOCOL.md` 约束。本页只提供人类可读速查。
