# Agent 任务五阶段工作流

这是一份给人看的协作速查，不是第二套机器状态机。精确阶段、授权和任务状态以息壤 StateStore 与机器契约为准。

## 1. 理解目标

- 读取当前项目、已有资料和适用规则。
- 把口语需求整理成可验证目标。
- 标出缺失信息、假设和不会处理的内容。

## 2. 冻结边界

- 第一次产生副作用前展示开工边界。
- 说明写入范围、排除项、外部影响、恢复方式和验收方。
- 用户确认后，把决定绑定到一个执行包络和一个主任务。

## 3. 连续执行

- 在已经确认的边界内实现，不逐文件重复询问。
- 需要并行或接力时，只分配更小的 worker 范围。
- 阶段变化或会话交接前更新 handoff。

## 4. 验证与修复

- 运行离改动最近、能够复现的验证。
- 主动寻找缺陷；发现问题后修复并重新验证。
- 没有新证据或重复失败时停止无效循环，换策略或请求决定。

## 5. 提交验收

- 列出精确变化、验证证据和剩余风险。
- 执行者只提交为 `submitted`。
- 由执行者之外的具名验收方接受、退回或取消。
