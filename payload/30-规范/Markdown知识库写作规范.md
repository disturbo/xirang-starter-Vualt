# Markdown 知识库写作规范

## 目标

让人和 Agent 都能快速理解、检索、引用和维护文档。

## 基本规则

1. 一篇文档只解决一个主要问题，标题直接表达主题。
2. 先写结论，再写依据、影响、建议和未验证项。
3. 使用清晰标题层级，不用加粗文字冒充标题。
4. 列表适合并列事项；表格只用于确实需要逐项比较的内容。
5. 链接到已有真源，不复制多份同一规则。
6. 引用外部资料时记录来源和日期；不把推测写成事实。
7. 文件名使用稳定主题，不在标题中堆叠“最终版、最新版、真最终”等字样。

## 推荐 Frontmatter

```yaml
---
title: 文档标题
status: draft
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: []
---
```

只有确实会被检索、筛选或自动化消费的字段才进入 Frontmatter。

## 隐私与安全

- 不记录密钥、令牌、Cookie、恢复码或账号密码。
- 不复制聊天会话、个人目录、设备路径或无关身份信息。
- 示例统一使用占位符，不使用真实项目和真实人员数据。
