# 规范

本目录只保存跨项目稳定、能够指导后续工作的规则。具体项目的品牌、业务、字段和页面规则应放入对应项目内部，不进入通用规范。

冲突时先采用机器契约、根 `AGENTS.md` 和项目内更具体的上位规则；本目录同一规则域只保留一个 `status: current` 的主规范。来源、生命周期、目录职责和归档见 [[知识库信息架构与生命周期规范]]。
