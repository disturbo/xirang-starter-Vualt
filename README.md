# 息壤 V9.7.2 Starter

息壤把普通文件夹变成一个可授权、可约束、可恢复、可验收的 Agent 工作区。

发行只提供一个完整包。它的根目录就是可直接打开的 Obsidian Vault，同时在隐藏分发层保留事务安装器、升级基线和完整校验。

## 第一次使用

1. 下载并解压 `xi-rang-v9.7.2-starter.zip`。
2. 在 Obsidian 中把整个解压目录作为仓库打开，首屏进入 `🏠-Home.md`。
3. 把根目录 `AGENT-SETUP.md` 交给当前任意可访问文件的 Agent，让它校验包并完成息壤激活。Obsidian 已经打开过没有关系，安全校验会区分正常配置变化和包损坏。
4. Things 主题、通用 CSS、必要插件、通用预设和可移植 Skill 已在包内；按提示启用随包社区插件即可。

## 已经在使用

1. 下载同一个 `xi-rang-v9.7.2-starter.zip`。
2. 把完整包和旧工作区位置交给当前能访问本机文件的 Agent。
3. Agent 先只读识别、展示保留与备份范围；用户回复开始后再升级。

不要用启动包或 Git clone 直接覆盖已有工作区。

## 同一个包的四种判断

| 检查结果 | Agent 的动作 |
|---|---|
| 没有息壤 | 在目标工作区全新安装 |
| 已识别旧版 | 先备份，再升级和迁移 |
| 已是 V9.7.2 | 校验或修复，不重复安装 |
| 版本不明、目标不唯一或无法恢复 | 停止写入并给出诊断编号 |

## 一个 Vault，一套隐藏分发层

```text
payload/                      单一发行来源：控制面、宪法与知识库种子
starter-vault/                Obsidian、插件、主题、Skill 与新人入口
.xirang/distribution/upgrade  构建后隐藏的事务升级载荷
tools/ + tests/               构建、完整校验、extras 合并和回归测试
```

构建器把同一 payload 展开到 Vault 根目录，并从同一来源生成隐藏升级载荷。生命周期清单把文件分成四类：机器契约强更新、根规则受管块合并、知识库种子仅缺失时补齐、用户运行数据永不写入。升级不会覆盖同事已经修改的首页、MOC、模板或教训库。

16 个通用插件只携带程序和许可证，不带个人数据，也不包含息壤专用 Obsidian 插件；其中 Floating TOC 悬浮大纲与增强链接插件已启用，并通过通用预设在首次安装时补齐配置。默认工作区不再打开占据侧栏的标题树。Skill 只携带公开可移植版本，不复制宿主缓存和项目专用能力。

## 当前平台承诺

V9.7.2 发行目标只承诺 macOS 和 Python 3.11+。包内置多种常见 Agent 宿主模板并通过 `platforms.json` 开放扩展，不把任何名单定义为固定角色。安装器只应用当前调用 Agent 的入口；未登记 Agent 使用通用工作区入口，其他模板不冒充已安装。安装器会在写入前检查平台；不满足条件时停止，不会尝试半安装。

完整发行与恢复口径见 [GOVERNANCE.md](GOVERNANCE.md)。
