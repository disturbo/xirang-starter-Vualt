# V9 规范管辖权索引

> 目的：给 V9 第一反射器的规范冲突扫描提供一份可审计的权威清单。每个规则域只允许一个 primary 文档负责定义口径；supporting 文档只能展开、速查或落地，不反向改写 primary。

## 判定规则

| 角色 | 含义 |
|---|---|
| primary | 该规则域的口径真源；冲突时以它为准 |
| supporting | 辅助说明、速查、部署或落地文件；不得定义相反口径 |
| inactive | 被替代、归档或仅历史参考的文件；若仍标 active/正式，则视为冲突信号 |

## 冲突处理

1. primary 与 supporting 口径冲突时，先按 primary 执行，再开规范修订任务。
2. supporting 需要改变规则时，必须同步更新 primary 或在 primary 中明确授权。
3. inactive 文件若仍被新任务引用，只能作为历史背景，不得作为当前执行依据。
