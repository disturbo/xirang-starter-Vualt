## 1. 版本关系

```
V8（正文，已冻结 2026-05-19，已废弃 2026-05-28）
 └── V8.5（运行时工具层，2026-05-24 ~ 2026-05-25）

      ├── Phase 2+3: 通信队列 + 成本调度

V9（合规框架，2026-05-28 ~ 当前）

 ├── 9.1.0: 自包含重写（脱离 V8 依赖）
 ├── 9.2.0: 完整版展开（六脉/六步/外部Agent/运行时契约/单人版降级）
 ├── 9.2.1: Hook参数化 + 三阶段成本事件 + 模型降级链 + 平台能力矩阵
 ├── 9.2.2: Skill 共享治理订正 + CLI-first 薄 skill + project_slug-prd-spec v3.3.5 共享
```

## 5. 兼容性声明

- **Python**: >= 3.9（全部脚本使用 `from __future__ import annotations`）
- **Bash**: >= 4.0（v8-handshake.sh 使用 `local -a` 等特性）
- **运行环境**: macOS / Linux
- **依赖**: 无外部 pip 包，全部标准库
- **VAULT_ROOT**: 环境变量或默认 `~/Desktop/obsidianVault`

## 6. 封版规则

1. V9.3.0 发布后，`.standards/` 与巡检工具继续接受 bugfix（版本号 patch +1）
2. 新 gate 规则在 V9 patch 中追加（9.3.x...）
3. 架构性变更（新触发模型、新分发目标）需升 V9.3
4. V8/V8.5 文档已全部归档，不再维护
5. 实验性工具（v0.x）不受封版约束
