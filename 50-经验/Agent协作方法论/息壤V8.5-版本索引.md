# 息壤版本索引

## 1. 版本关系

```
V8（正文，已冻结 2026-05-19，已废弃 2026-05-28）
 └── V8.5（运行时工具层，2026-05-24 ~ 2026-05-25）
      ├── Phase 0+1: Schema统一 + 子任务运行时记录
      ├── Phase 2+3: 通信队列 + 成本调度
      ├── Phase 4:   Gate强制机制
      └── Phase 5A:  版本定格
V9（合规框架，2026-05-28）
 ├── 二元触发器：替代 M0-M5 档位判定作为合规入口
 ├── prompt-build.py 单源分发（7 平台）
 ├── V9 写入声明格式统一
 └── gate-enforce v1.1.0（WRITE_WITHOUT_V9_PREFIX）
```

**V8/V8.5/V9 的关系**：V9 替代 V8 的合规判定层（"写文件吗？"二元触发器替代 M0-M5 分档）。V8.5 运行时工具链（v8-handshake.sh / gate-enforce.py / subtask-record.py 等）继续有效。V8 正文降级为设计参考文档。

## 5. 兼容性声明

- **Python**: >= 3.9（全部脚本使用 `from __future__ import annotations`）
- **Bash**: >= 4.0（v8-handshake.sh 使用 `local -a` 等特性）
- **运行环境**: macOS / Linux
- **依赖**: 无外部 pip 包，全部标准库
- **VAULT_ROOT**: 环境变量或默认 `$VAULT_ROOT`

## 6. 封版规则

1. V9.0 发布后，`.standards/` 工具继续接受 bugfix（版本号 patch +1）
2. 新 gate 规则在 V9 patch 中追加（9.0.1, 9.0.2...）
3. 架构性变更（新触发模型、新分发目标）需升 V9.1
4. V8/V8.5 文档已全部归档，不再维护
5. 实验性工具（v0.x）不受封版约束
