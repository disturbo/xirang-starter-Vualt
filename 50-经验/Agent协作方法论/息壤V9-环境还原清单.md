# 息壤 V9 环境还原清单

> 按照本清单，在一台全新 Mac 或 Windows 电脑上还原息壤多智能体协作系统的所有必要条件。

## 1. 硬件与系统要求

### Mac

| 项目 | 最低要求 | 推荐 |
|------|---------|------|
| 芯片 | Apple Silicon (M1+) | M2 Pro+ |
| 内存 | 16GB | 32GB |
| 磁盘 | 50GB 可用空间 | 100GB+ |
| 系统 | macOS 14 (Sonoma) | macOS 15 (Sequoia) |
| 网络 | 可访问 GitHub / npm / pip | 稳定代理 |

### Windows

| 项目 | 最低要求 | 推荐 |
|------|---------|------|
| 处理器 | x64 或 ARM64 | 近 3 年的 CPU |
| 内存 | 16GB | 32GB |
| 磁盘 | 50GB 可用空间 | 100GB+ |
| 系统 | Windows 10 (21H2+) | Windows 11 |
| 网络 | 可访问 GitHub / npm / pip | 稳定代理 |
| L3 额外要求 | WSL2（`wsl --install`） | Ubuntu 22.04+ |

> Ollama 本地推理（bge-m3 embedding）需要至少 4GB 显存/内存。Mac Apple Silicon 统一内存可直接使用；Windows 独显或集显均可。

## 2. 基础工具安装（按顺序）

> 每个工具都给出 Mac 和 Windows 两种安装方式。只看自己平台的命令即可。
> L3 的 Windows 用户装完 WSL2 后，在 Ubuntu 终端中按 Mac/Linux 方式操作。

### 2.1 包管理器

```bash
# Mac —— Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

```powershell
# Windows —— winget 已自带，无需安装
# 验证：在 PowerShell 中执行
winget --version
```

### 2.2 Python

```bash
# Mac
brew install python@3.14

# Windows（L3 走 WSL2）
# WSL2 Ubuntu:
sudo apt update && sudo apt install -y python3 python3-pip
# 或 Windows 原生:
winget install Python.Python.3.12
```

验证（两个平台一样）：
```bash
python3 --version  # >= 3.9，推荐 3.14+
```

> 所有 `.standards/` 脚本使用 `from __future__ import annotations`，最低兼容 Python 3.9，但推荐 3.14+。

### 2.3 Node.js

```bash
# Mac
brew install node@22

# Windows
winget install OpenJS.NodeJS.LTS
# 装完后重新打开 PowerShell
```

验证（两个平台一样）：
```bash
node --version  # >= 22.x
npm --version
```

### 2.4 Bun

```bash
# Mac
brew install oven-sh/bun/bun

# Windows / WSL2
curl -fsSL https://bun.sh/install | bash
```

验证：`bun --version  # >= 1.3.13`

### 2.5 Ollama

```bash
# Mac
brew install ollama

# Windows —— 方式 A：官网下载安装包
# https://ollama.com/download/windows → 双击安装

# Windows —— 方式 B（WSL2）：
curl -fsSL https://ollama.com/install.sh | sh
```

启动和拉取模型（两个平台一样）：
```bash
ollama serve &
ollama pull bge-m3:latest
ollama list | grep bge-m3  # 验证
```

> bge-m3 参数：1024 dims, 8192 context length, 多语言支持。

## 7. 验证清单

### 7.1 一键验证脚本

**Mac / WSL2（Bash）：**

```bash
#!/bin/bash
# 保存为 ~/verify-xirang.sh 并执行: bash ~/verify-xirang.sh
set -e
echo "=== 息壤 V9 环境验证 ==="

echo "[1/8] Python..."
python3 --version

echo "[2/8] Node..."
node --version

echo "[3/8] Ollama + bge-m3..."
ollama list | grep bge-m3

echo "[4/8] GBrain..."
~/.npm-global/bin/gbrain status 2>/dev/null | head -5

echo "[5/8] Claude Code..."
claude --version 2>/dev/null || echo "claude-code not in PATH"

echo "[6/8] Gate-enforce..."
python3 "$VAULT_ROOT/.standards/gate-enforce.py" pre-write --file _temp/test.md --json 2>/dev/null && echo "OK" || echo "WARN (expected if no task)"

echo "[7/8] Prompt-build verify..."
python3 "$VAULT_ROOT/.prompt-src/prompt-build.py" --verify 2>/dev/null && echo "OK" || echo "DRIFT"

echo "[8/8] Standards scripts syntax..."
find "$VAULT_ROOT/.standards" -name "*.py" -exec python3 -c "import py_compile; py_compile.compile('{}', doraise=True)" \; && echo "All .py OK"

echo "=== 验证完成 ==="
```

**Windows 原生（PowerShell，仅 L0-L2）：**

```powershell
# 保存为 verify-xirang.ps1 并执行: .\verify-xirang.ps1
Write-Host "=== 息壤 V9 环境验证（Windows）==="

Write-Host "[1/4] Node..."
node --version

Write-Host "[2/4] Claude Code..."
try { claude --version } catch { Write-Host "claude-code not in PATH" }

Write-Host "[3/4] Obsidian Vault..."
$vault = "$env:USERPROFILE\Desktop\obsidianVault"
if (Test-Path $vault) { Write-Host "Vault 目录存在: $vault" } else { Write-Host "未找到 Vault!" }

Write-Host "[4/4] CLAUDE.md..."
if (Test-Path "$vault\.claude\CLAUDE.md") { Write-Host "CLAUDE.md 存在" } else { Write-Host "未找到 CLAUDE.md" }

Write-Host "=== 验证完成 ==="
```

## 8. 按阶段裁剪

根据用户成熟度，按需安装:

| 阶段 | 画像 | 需要安装 | 可跳过 | Windows 额外 |
|:---:|------|---------|--------|:---:|
| **L0** | 浏览者 | Obsidian | 全部 CLI 工具 | 无 |
| **L1** | 问答者 | + Claude Code + `.claude/CLAUDE.md` | OpenClaw / Hermes / GBrain / Codex | 无 |
| **L2** | 产出者 | + `.standards/` + hooks + `.prompt-src/` + Ollama | OpenClaw / Hermes / Codex | 无 |
| **L3** | 协作者 | 全部（含 OpenClaw + Hermes + GBrain + Codex + Cron） | 无 | **WSL2** |

### L0 安装路径（2 分钟）

1. 安装 Obsidian（Mac: `brew install --cask obsidian` / Win: `winget install Obsidian.Obsidian`）
2. 打开 Vault
3. 浏览笔记

### L1 安装路径（10 分钟）

1. L0 全部
2. 安装 Node.js（Mac: `brew install node@22` / Win: `winget install OpenJS.NodeJS.LTS`）
3. `npm install -g @anthropic-ai/claude-code`（两个平台一样）
4. 配置 API key（`claude login`）
5. 确认 `.claude/CLAUDE.md` 存在

### L2 安装路径（20 分钟）

1. L1 全部
2. 安装 Python 和 Ollama
   - Mac: `brew install python@3.14 ollama`
   - Win: `winget install Python.Python.3.12` + 从 ollama.com 下载
3. `ollama pull bge-m3:latest`
4. 确认 `.standards/` 目录完整（32 文件）
5. 确认 `.prompt-src/` 目录完整
6. 运行 `python3 .prompt-src/prompt-build.py --verify`

### L3 安装路径（1 小时）

1. L2 全部
2. **Windows 用户先装 WSL2**：`wsl --install`（管理员 PowerShell），后续在 Ubuntu 中操作
3. 安装 GBrain、OpenClaw、Hermes、Codex
4. 配置 `~/.hermes/SOUL.md`
5. 配置 `~/.openclaw/workspace/`（含 AGENTS.md + skills/v8-runtime/）
6. 配置 `~/.codex/instructions.md`（如适用）
7. `gbrain init` + 首次 `gbrain dream`
8. 配置 crontab（3 条）；WSL2 需 `sudo service cron start`
9. 运行全量验证脚本

## 10. 故障排除

| 问题 | 原因 | 解决 | 平台 |
|------|------|------|:---:|
| `gbrain: command not found` | npm global bin 不在 PATH | `export PATH="$HOME/.npm-global/bin:$PATH"` | 两者 |
| `ollama: connection refused` | 服务未启动 | Mac: `ollama serve &`；Win: 启动 Ollama 桌面应用 | 两者 |
| `gate-enforce.py` 报错 | Python 版本过低 | 升级到 3.9+ | 两者 |
| `prompt-build --verify` DRIFT | 手动改了目标文件 | `python3 .prompt-src/prompt-build.py --apply --apply-block` | 两者 |
| Hook 无权限 | 文件缺少执行权限 | `chmod +x .standards/hooks/*.sh` | Mac/WSL2 |
| 状态文件 Schema 错误 | 手工编辑格式错误 | `python3 .standards/agent-state-lint.py --fix` | 两者 |
| `.sh` 脚本跑不了 | Windows 无 Bash | 安装 WSL2（L3 必须） | Win |
| `npm` 装了但找不到 | PATH 未刷新 | 关闭并重新打开 PowerShell | Win |
| WSL2 cron 不运行 | 服务未启动 | `sudo service cron start`，或配 `/etc/wsl.conf` 自启 | Win |
| 路径中有中文 | Windows 用户名含中文 | 把 Vault 放到 `D:\obsidianVault` 等无中文路径 | Win |
