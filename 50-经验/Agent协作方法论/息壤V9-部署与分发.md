# 息壤 V9 部署与分发

> V9 合规内容如何从单一源文件分发到 7 个 Agent 平台。

## 1. 核心工具

```bash
python3 .prompt-src/prompt-build.py [--apply] [--apply-block] [--verify]
```

## 2. 源文件结构

```
.prompt-src/
├── v9-compliance-block.md      # V9 合规内容（唯一真相源）
├── preflight-auto-template.md  # 自动平台 pre-flight 模板
├── prompt-base.md              # 通用基类（路径/路由/工具/约束）
├── prompt-build.py             # 构建脚本
└── agents/
    ├── claudian.delta.md       # Claudian 特化配置
    ├── qingmeisu.delta.md      # 青霉素特化配置
    ├── hongmeisu.delta.md      # 红霉素特化配置
    └── workbuddy.delta.md      # WorkBuddy 特化配置
```

## 3. 目标平台

### 3.1 自动平台（--apply 全文覆写）

| Agent | 目标文件 | 平台 |
|-------|---------|------|
| Claudian | `.claude/agents/claudian.md` | Claude Code |
| 青霉素 | `.claude/agents/qingmeisu.md` | Claude Code |
| WorkBuddy | `.claude/agents/workbuddy.md` | Claude Code |
| 红霉素 | `.codex/instructions.md` | Codex |

生成公式：`prompt-base.md` + 注入 `v9-compliance-block.md` + 渲染 `preflight-auto-template.md` + `{agent}.delta.md`

### 3.2 手动平台（--apply-block 仅替换标记区）

| Agent | 目标文件 | 平台 |
|-------|---------|------|
| 头孢 | `~/.hermes/SOUL.md` | Hermes |
| 阿莫西林 | `~/.openclaw/workspace/AGENTS.md` | OpenClaw |
| 全局 | `.claude/CLAUDE.md` | Claude Code 项目配置 |

替换范围：`<!-- V9-COMPLIANCE-BLOCK-START -->` 到 `<!-- V9-COMPLIANCE-BLOCK-END -->` 之间的内容。
手动平台的 pre-flight 格式各自维护（使用平台特定脚本/API）。

## 4. 模板变量

| 变量 | 说明 | 示例 |
|------|------|------|
| `{{AGENT_ID}}` | Agent 英文 ID | `claudian` |
| `{{AGENT_CN}}` | Agent 中文名 | `Claudian` |

| `{{KANBAN_PATH}}` | 看板路径 | `00-MOC/多智能体协作看板.md` |

## 5. 操作流程

### 5.1 修改合规规则

```bash
# 1. 编辑源文件
vim .prompt-src/v9-compliance-block.md

# 2. 应用到自动平台
python3 .prompt-src/prompt-build.py --apply

# 3. 应用到手动平台
python3 .prompt-src/prompt-build.py --apply-block

# 4. 验证全部一致
python3 .prompt-src/prompt-build.py --verify
```

### 5.2 新增 Agent

1. 创建 `.prompt-src/agents/{new_id}.delta.md`
2. 在 `prompt-build.py` 的 `TARGETS` dict 添加条目
3. 运行 `--apply`

### 5.3 废弃 Agent

1. 将条目从 `TARGETS` 移入 `DEPRECATED`
2. 目标文件不再更新（保留历史内容）

## 6. 内容 Hash 机制

生成文件头部：
```
<!-- AUTO-GENERATED by prompt-build.py @ v{hash} -->
```

- Hash 基于生成内容（不含头部本身）的 SHA256 前 8 位
- 不含日期 → 内容不变时 hash 不变 → 无噪音 diff
- `--verify` 通过比较当前文件内容（去头）与重新生成的内容判定是否漂移

## 7. 验证失败处理

```bash
$ python3 .prompt-src/prompt-build.py --verify
# 如果输出 DRIFT DETECTED:

# 选项 A: 接受源文件变更，重新应用
python3 .prompt-src/prompt-build.py --apply --apply-block

# 选项 B: 检查手动修改是否有意
git diff .claude/agents/  # 查看具体变更
```
