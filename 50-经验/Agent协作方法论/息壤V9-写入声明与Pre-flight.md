# 息壤 V9 写入声明与 Pre-flight

> 确定要写文件后，按档位执行对应流程。

## 1. M3 — 单文件轻量操作

### 声明（任务开始时输出）

```
V9 写入声明：{文件路径} | {动作摘要}
```

示例：`V9 写入声明：02-项目管理/运行日志/2026-05-28.md | 追加今日任务记录`

### 收工

追加一行到 `02-项目管理/运行日志/YYYY-MM-DD.md`：

```
- HH:MM | M3 | 动作摘要 | 结果 | 产物路径(可选)
```

不更新状态文件，不写事件流。

---

## 2. M4 — 多文件/交付物

### 声明（回复开头输出）

```
V9 已激活：
- 档位：M4
- 任务：{任务名}
- 写入范围：{将写入的文件/路径列表}
- 验收方：{用户 / 具体Agent名}
```

### Pre-flight 三步

```
1. 亮灯
   - 更新 02-项目管理/智能体状态/{中文名}.md — status -> busy
   - 追加事件到 02-项目管理/智能体状态/智能体事件.jsonl：
     {"ts":"ISO","event":"task_start","agent":"{id}","task_id":"T-YYYYMMDD-NN","task":"任务名","task_size":"S|M|L"}

2. 声明（上方格式）

3. 执行
```

### 收工三件套

1. **产物清单**：列出所有写入文件 + 一句话描述
2. **自查结果**：路径合规 / frontmatter / 无装饰性emoji / 无越权声明 / 看板
3. **验收建议**：验收方 + 检查点 + 风险假设
4. 更新状态文件 status -> idle, current_task -> null
5. 追加 task_end 事件（只记录任务、结果与身份）
6. 看板 Handoff：`00-MOC/多智能体协作看板.md`

---

## 3. M5 — 跨 Agent / 长任务

### 声明

```
V9 已激活：
- 档位：M5
- 任务：{任务名}
- 写入范围：{路径}
- 拆分计划：{子任务数} 个子任务
- 验收方：{验收链}
```

### 额外要求

- 子任务使用 `v8_spawn` 或 `subtask-record.py` 记录
- 长任务(>120s) 写 heartbeat 到事件流
- 必须写 Handoff

---

## 4. 失败判定（5 类）

| 类型 | 表现 | 处理 |
|------|------|------|
| 范围溢出 | 写了声明外的文件 | 暂停 → 补充声明 → 继续 |
| 格式缺失 | 产出无 frontmatter | 补写 frontmatter |
| 品牌违规 | 错误品牌名/色值 | 立即修正 |
| 升档不足 | M3 写了多文件但未升 M4 | 补声明 + 状态亮灯 |
| 静默写入 | 写了文件完全无声明 | 最严重违规 — 回退 + 重新声明 |

---

## 5. 升降档规则

| 触发 | 动作 |
|------|------|
| M3 发现需写第 2 个文件 | 升为 M4，补完整声明 + 亮灯 |
| M4 发现需跨 Agent 协作 | 升为 M5，补预算 + 拆分 |
| M4/M5 执行中发现只需改 1 个文件 | 可降为 M3，但已亮灯的收工不可省略 |
