# 息壤 V9 子任务与通信

> M5 任务拆分子任务时的运行时记录 + Agent 间消息队列。

## 1. 子任务生命周期

### 1.1 状态机

```
SPAWNED → RUNNING → COLLECTED
                  ↘ FAILED → RETRIED → COLLECTED
                  ↘ TIMEOUT → DESTROYED
```

### 1.2 工具

| 工具 | 命令 | 用途 |
|------|------|------|
| subtask-record.py | `create` | 创建子任务记录 |
| subtask-record.py | `transition` | 状态转换 |
| subtask-record.py | `collect` | 收集结果 |
| subtask-record.py | `destroy` | 超时销毁 |
| subtask-query.py | `--active` | 查询活跃子任务 |
| subtask-query.py | `--stale` | 查询超时子任务 |
| subtask-query.py | `--summary` | 汇总统计 |

### 1.3 使用场景

```bash
# M5 spawn 子任务
python3 .standards/subtask-record.py create \
  --task-id T-20260528-01 \
  --sub-id S-01 \
  --agent claudian \
  --type "PRD编写" \
  --model sonnet

# 子任务完成
python3 .standards/subtask-record.py collect \
  --task-id T-20260528-01 \
  --sub-id S-01 \
  --result "done" \
  --output "10-项目/{项目名}/模块/PRD.md"
```

### 1.4 v8_handshake 集成

```bash
source .standards/v8-handshake.sh
v8_spawn claudian "T-20260528-01" "S-01" "编写PRD" "sonnet"
v8_collect "T-20260528-01" "S-01" "done" "产物路径"
```

## 2. 消息队列

### 2.1 概念

Agent 间结构化异步通知。不替代直接调用，用于：
- 非阻塞通知（"我完成了 X"）
- 异步请求（"请审核 Y"）
- 广播事件（"Z 已上线"）

### 2.2 工具

```bash
# 发送消息
python3 .standards/msg-queue.py enqueue \
  --from claudian \
  --to hongmeisu \
  --type review_request \
  --payload '{"file": "10-项目/XX/PRD.md", "priority": "normal"}'

# 接收消息
python3 .standards/msg-queue.py dequeue --agent hongmeisu

# 查看待处理
python3 .standards/msg-queue.py peek --agent hongmeisu

# 确认处理
python3 .standards/msg-queue.py ack --msg-id MSG-001

# 过期清理
python3 .standards/msg-queue.py expire --hours 48
```

### 2.3 消息类型

| type | 含义 | 典型场景 |
|------|------|---------|
| `task_handoff` | 任务交接 | M5 子任务分发 |
| `review_request` | 审核请求 | PRD/代码评审 |
| `status_update` | 状态通知 | "我完成了 X" |
| `error_report` | 错误上报 | 异常需人工 |
| `budget_alert` | 预算告警 | 60% / 100% |

## 3. Spawn 预算检查

### 3.1 spawn 前评估

```bash
python3 .standards/spawn-budget-check.py check \
  --task-id T-20260528-01 \
  --type "PRD编写" \
  --model opus \
  --json
```

返回：
- exit 0: 绿灯，可 spawn
- exit 1: 黄灯，建议降级模型（返回 model_recommended）
- exit 2: 红灯，所有模型超预算

### 3.2 模型降级建议

```bash
python3 .standards/spawn-budget-check.py advise \
  --task-id T-20260528-01 \
  --remaining-budget 5.0
```

降级链：`opus → sonnet → haiku`

## 4. 最大并行数

- spawn 最大并行：6 个子任务
- 超过 6 个需排队或合并

## 5. 超时规则

| 任务类型 | 默认超时 | 心跳间隔 |
|---------|---------|---------|
| S (小) | 5min | 无需 |
| M (中) | 30min | 120s |
| L (大) | 2h | 120s |
| XL (超大) | 8h | 120s |

超过默认超时 + 无心跳 → 自动标记 TIMEOUT → WorkBuddy 介入。
