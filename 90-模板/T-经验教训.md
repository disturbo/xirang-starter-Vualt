# T-经验教训

> 用于记录单条经验教训的模板。
> 对齐 [[教训库]] 的 E-编号体系。

---

## 索引条目（追加到教训库索引表）

```markdown
| {日期} | [[{来源模块}]] | {🔧/✅/🚨/❌} | E-{YYYYMMDD}-{##} · {标题短语} |
```

## 详情条目（追加到教训库详情区）

```markdown
### E-{YYYYMMDD}-{##} · {标题短语}

**模块**：[[{模块名}]] · 阶段：{PRD/原型/评审/交付/协作/采集}
**类型**：{✅ 做对了 / ❌ 踩坑了 / 🔧 缺失了 / 🚨 红线}

**事件**：
{具体发生了什么——用 2~5 句话描述事件经过}

**影响**：
- {影响1：对项目/进度/质量的具体影响}
- {影响2}

**根因**：
{为什么会发生——挖到流程/规范/习惯层面，不只停留在表象}

**解决**：
- ✅ {已执行的动作}
- 🔧 {待执行的动作}
- ❌ {需要避免的做法}

**核心启发**：
{一句话总结——可以提炼为规则或口号}
```

---

## 类型标记说明

| 标记 | 含义 | 使用场景 |
|---|---|---|
| ✅ | 做对了 | 值得复用的成功经验 |
| ❌ | 踩坑了 | 犯了错需要避免重犯 |
| 🔧 | 缺失了 | 发现规范/流程缺失 |
| 🚨 | 红线 | 违反铁律（写进协作看板） |
